# 🏦 Banking System – Java

A simple **Banking System application built using Java** that allows users to perform basic banking operations such as checking account balance, depositing money, withdrawing money, and viewing account details.

This project was created to practice **Core Java concepts, Object-Oriented Programming (OOP), ArrayList, methods, conditional statements, loops, and user input handling**.

## 📌 Features

* 👤 Create and manage bank accounts
* 💰 Check account balance
* ➕ Deposit money
* ➖ Withdraw money
* 📋 View account details
* 🔍 Search for an account
* 🧾 Perform basic banking transactions
* 🚪 Exit the application safely
* 📦 Store account information using `ArrayList`

## ⚙️ How the Application Works

The application provides a menu-driven interface where the user can select different banking operations.

### Example Menu

```text
========== BANKING SYSTEM ==========

1. Create Account
2. Check Balance
3. Deposit Money
4. Withdraw Money
5. View Account Details
6. Search Account
7. Exit

Enter your choice:
```

The user selects an option and provides the required information. The program then performs the selected banking operation.

## 💻 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/banking-system-java.git
```

### 2. Open the Project

Open the project in any Java-supported IDE, such as:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile and Run

Run the main Java class containing the `main()` method.

Or, using the terminal:

```bash
javac Main.java
java Main
```

> Replace `Main.java` with the name of your main Java file if it is different.
